# UI 闭环与本机旧插件对照

## 已补齐的链路

- 打开/新建/删除当前会话后，宿主发送真实 transcript；界面恢复用户、助手、工具调用和结果，不再用一条“已打开会话”代替历史。
- 页面重载时从当前会话恢复；切换会话清理待发送附件。
- 工具结果包含 success、payload、错误码和耗时。payload 根部数据不会在格式化时丢失；下一轮历史保留工具证据，并提醒重新查询当前模型状态。
- 工具结果数组展示为表格，保留完整 JSON；表格预览最多 50 行、8 列。
- Markdown 支持标题、代码块、列表、引用、表格和 HTTP(S) 链接；转义原始 HTML，拒绝脚本链接。外链由宿主交给系统浏览器。
- 附件显示大小，支持按 attachmentId 移除，宿主校验实际字节长度和数量（50 MB / 10 个）。
- API 状态区分“已配置”和“测试通过”；设置变更使测试状态失效，失败可见。
- 工具目录显示实际参数 Schema 和是否支持预演；技能库尚未接入时明确说明。

## 与本机旧版的关系

本机有原始 Loader 与 HybridUI 两个启用的 addin。HybridUI 使用旧 RevitAi.Hybrid.Core，并部署了旧 RevitAi.Core / RevitAi.Revit 等程序集；新版 UI 改由 BridgeRuntime 调用开源工具层，不依赖这些旧工具二进制。两者界面资源同源，不代表工具行为相同。

本机历史归档分别保存 Original120、CleanRoom121 和 HybridExternalPriority；归档说明明确复杂工具的性能和边界覆盖仍有差距。不能据此认定当前 HybridUI 每次调用都走第三方优先通道，实际应以实时目录、加载情况和结果为准。

新版当前暴露 145 个工具（119 启用主契约 + 26 扩展）。这是目录覆盖，不是 145 项实机效果验收。卫星图和在线库等不可用能力未冒充可执行工具。

## 尚未完成的 UI / 产品能力

- 模型文字响应仍按整轮返回，尚无逐 token 流式输出。
- 技能/记忆库仍未与实际实现接通。
- 目前结果展示为表格/JSON；尚无通用的构件点击定位、导出文件中心、图片结果预览。
- 附件预处理具备 PDF/CAD 路径，但缺少逐页预览和处理进度；历史只恢复消息与工具记录，未恢复完整附件预览。
- 尚无统一的事务预览确认面板；只有标记支持预演的工具才能使用 dry-run。
- 当前代码和旧程序集存在同名宿主类型，不能在同一 Revit 进程中直接并排加载替换后作对比。

## 验证范围

自动化回归覆盖取消边界、目标文档绑定、跨轮结果保存、历史恢复、HTML 转义、表格与链接、配置状态。Revit API 引用的宿主 Release 构建通过。浏览器使用模拟宿主消息检查页面真实渲染和附件移除，不等于 Revit WebView2 / 真实模型运行验证。

保留现有插件安装。候选版本应先在独立测试环境中使用同一模型副本，对查询、标高/墙/房间、参数、CAD/PDF、导出、取消与文档切换逐项比对，再决定是否替换。

## 本次实机旧版基线

启动现有 Revit 2027 后，使用最近项目的工作副本进行只读调用。旧插件实时目录为 124 项；与新版 145 项目录共有 118 个同名工具。旧版独有 6 项：save_memory、pdf_document_manager、cad_file_manager、execute_skill、web_fetch、import_satellite_map。新版多出的 27 项主要是绘图计划、批处理、视图、保存与建模扩展。

旧版 ping、标高、轴网、视图和当前视图查询均已返回成功。该基线证明旧插件当前可用，不代表新桥接已经实机验收通过。PDF/CAD 附件的自动预处理存在于新版中，但不能替代旧版这两个文件管理工具的全部操作。

## 标准 Revit 插件验收入口

旧插件 execute_code 的安全检查拒绝了新 DLL 加载脚本（禁止使用 Path），所以那次调用没有执行新桥接查询。没有通过修改脚本规避此检查。

`tests/Revit.ReadOnlyProbe` 是独立、可选的原生 IExternalApplication 测试入口，已通过 Revit 2027 API 引用的 Release 编译。默认不会由构建或打包脚本安装。配置必须明确指定模型副本、候选 DLL 目录和输出路径；只在指定模型激活后的 Idling 上执行一次，工具名固定为四个只读查询。独立加载上下文加载新工具实现。它不启动事务、不修改选择或视图、不保存文件。

临时注册该测试入口、启动单独的 Revit 进程后才能完成实机对比。此步骤已获授权并已执行，结果与限制见下方复测记录。

## 修复后实机复测

标准只读测试入口获得授权后在独立 Revit 2027 进程中执行，新 DLL 使用独立加载上下文。首次发现 get_all_views 混入模板、内部浏览器和明细表（79 对 19），并发现中文契约视图类型未映射到原生枚举名称。

工具层已修复这两个问题，保留原生 viewType，并补充中文 type；当前视图结果补充旧版 view_id / view_name / view_type 别名。工具回归为 353 项通过、0 项失败。

重新编译后再次对照：3 个标高、10 个轴网、19 个视图的 ID 集合全部一致，当前视图 ID 一致，四项查询无错误。临时测试入口已移除；原插件未替换，模型文件未保存。

该验证直接在 Revit API 上下文执行共用 dispatcher，未覆盖新版完整 WebView2 交互、真实管道取消或模型写入。轴网结果目前仍只有 ID/名称等基础字段，缺少旧版查询返回的曲线端点、方向、长度等几何信息；六项旧版独有能力及这些结果字段仍是后续补齐重点。
